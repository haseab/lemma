YOUR WORK IS YOURS

A private scratchpad.

Your page and undo history are stored in this browser on this device. We don’t collect your equations, pasted content, or usage analytics.

Clearing browser data can remove your page. Export a .lemma file for a copy you control. Private browsing may remove saved work when the session ends.

The site checks GitHub for published desktop releases. That request contains no scratchpad content.
